# Videos de Ritmo (@ritmo.ve)

Reel animado "Cómo reservar en ritmovenezuela.com" con voz de Paola (es-VE-PaolaNeural).

1. Edita el texto en `ritmo/guion.json` y súbelo: GitHub genera la voz y la deja en la rama `salida-ritmo`.
2. `plantilla/montaje.py <carpeta_voz>` ajusta la animación a la voz, crea los efectos de sonido y mezcla.
3. `plantilla/render2.mjs` renderiza los cuadros; ffmpeg une video + audio.
