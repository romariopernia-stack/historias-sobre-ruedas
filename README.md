# Historias sobre Ruedas – fábrica de videos

1. Escribe una historia en `historias/<nombre>.json` (ver `historias/lamborghini.json`).
2. Súbela al repo: GitHub Actions crea el video solo (voz Microsoft natural, animación, subtítulos, música).
3. Descarga el MP4 y el texto de la publicación en la pestaña **Actions → Crear video → Artifacts**.

Cambiar voz: Actions → Crear video → Run workflow → campo "voz".
Identidad de marca (colores, nombre, @): `video/src/brand.ts`.
